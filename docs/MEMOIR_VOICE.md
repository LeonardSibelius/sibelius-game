# MEMOIR_VOICE — Walt's eight messages (verbatim, 2026-07-16)

*Walt wrote these in one sitting after saying he was too discouraged to write
memoir sentences. This is the game's voice. Do not polish the anger out.*

## The correction that governs everything

**Walt did NOT design slot machines.** At Bally Technologies (2007) he built
the data warehouse and reporting systems behind the Slot Data System — never
the machines themselves. Any pitch text claiming "I designed slot machines
for a living" is FALSE and must not ship. The true pitch is better:

> During about 40 years, I rode desks in office cubicles building ordinary
> data processing software systems. Every one of those hand-coded projects
> either failed or is being retired. At 71, working with an AI, I finally
> built the machine myself.

## The metaphor (his words)

> "Working as a programmer in such places was like being a simple farmer
> using a plow, a donkey and a shovel, whereas modern coding with AI is like
> being a modern farmer with a tractor, a combine and other modern
> equipment."

## The eight messages to former employers

Walt: "Of course they will not see the messages, but it will be satisfying
to say them."

1. **SAIC** — "Hey SAIC, you could have used this AI skill on the CHCS
   project in 1988."
2. **IBM** — "Hey IBM, you could have used this AI skill in 1995 on the San
   Francisco Project for distributed Java."
3. **Seagate** — the horrible Seagate experience, 1998.
4. **Motorola** — the horrid Motorola experience, 2001.
5. **Northrop Grumman** — "Hey Northrop Grumman, you could have used this AI
   skill on the Electronic Family Housing system for the Navy in 2002."
6. **San Diego County** — Public Safety Probation Case Management System
   (PCMS), 2005.
7. **Bally Technologies** — Slot Data System (SDS), 2007. Data warehouse and
   reporting only — the closest he got to the floor, never the machine.
8. **US Army Recruiting** — iKrome, 2022. "Especially" iKrome. Now being
   retired, like nearly all of them.

("That does not include the horrid jobs I had before CHCS." — there is more
voice where this came from.)
