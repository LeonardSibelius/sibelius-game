# The Archaic Language Temple's statues

Walt, 2026-10-19: "I would like the old languages to be represented by ancient greek statues -
immobile figures to contrast with the lively AI dancers." The temple is a hidden door by the living
room's poker machine, seen with Code Vision (V), into the Olympus level (Hivemind's "Temple Of The
Gods" - a bought pack, gitignored, "Allows usage with AI: No").

All five are 3D scans of plaster casts in the Royal Cast Collection of SMK, the National Gallery of
Denmark, downloaded 2026-10-19 from SMK's open API (`api.smk.dk/api/v1/art/search`, filter
`has_3d_file:true`). Each is marked **Public Domain Mark 1.0**
(https://creativecommons.org/publicdomain/mark/1.0/): no conditions, no credit required. SMK's
"small" STL of each, binary, checked whole.

| Language | Statue | SMK object | File | Triangles | Why |

| COBOL | Doryphoros, the Spear Bearer | KAS11 | https://api.smk.dk/api/v1/download-3d/th83m405d_KAS11_small.stl | 275,182 | Carved to a written rulebook, Polykleitos's Canon; COBOL was written to a committee's specification and still runs the banks |

| Java | Poseidon or Zeus from Cape Artemision | KAS2100 | https://api.smk.dk/api/v1/download-3d/028711697_KAS2100_small.stl | 209,494 | It ruled the enterprise for twenty years; the thunderbolt is a NullPointerException |
| Python | Laocoön | KAS385 | https://api.smk.dk/api/v1/download-3d/d504rr247_KAS385_small.stl | 400,100 | A man strangled by serpents |

The `.stl` files are not in git: `*.stl` is not under Git LFS here, and they can always be fetched
again from the URLs above. They are backed up to E: with the rest of SourceArt.

The same API lists a caryatid from the Erechtheion (KAS838) and 365 other public-domain casts, if
the temple ever wants more.
