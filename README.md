# sibelius-game

Walt Parkman becomes the three-part entity Leonard Sibelius composed of himself, Claude Cowork and Claude Code



\## Setup



This project uses two QuadArt Fab Marketplace packs that are \*\*not redistributed via this repository\*\* — they are paid commercial assets, used under standard Fab license plus binding written permission for AI-foundational use. Each contributor needs to install them locally before opening the project in Unreal Editor.



1\. Own both packs on Fab:

&#x20;  - QuadArt \*\*House Furniture\*\* — https://fab.com/listings/7990c054-90fb-4b34-948e-55f963f67a6c

&#x20;  - QuadArt \*\*Modular House\*\* — same seller (https://fab.com/sellers/QuadArt)

2\. In Epic Games Launcher → Unreal Engine → Library → Fab Library, click \*\*Add To Project\*\* on each pack and select the `SibeliusGame` project.

3\. The packs install into `Content/HouseFurniture/` and `Content/ModularHouses/`. Both folders are gitignored — local-only by design.

4\. Open `SibeliusGame.uproject` in Unreal Engine 5.7. The office level (`L\_Office\_v02`) references these assets; without them you'll see missing-asset placeholders.
